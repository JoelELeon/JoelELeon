### 👨🏻‍💻 About Me

I'm a software developer and graphic designer from Puerto Rico with bachelor’s degrees in **Software Analysis & Development** and **Communication Technologies – Graphic Design**.

I enjoy combining programming, databases, cloud technologies, and visual design to build functional, secure, and user-friendly applications. My experience includes developing CRUD systems, responsive web applications, REST API integrations, authentication, role-based access, database management, and e-commerce functionality.

I’m currently focused on strengthening my skills in **Python, Django, backend development, AWS, Docker, data analysis, and cloud deployment** while building portfolio projects that solve practical problems.

Responsive e-commerce application developed with **Python and Django** for selling aromatic candles.

Key features include:

- Product catalog with search and filters
- Customer authentication
- Shopping cart and checkout
- Secure Stripe payments
- Order and inventory management
- Administrative dashboard
- Image storage with Cloudinary or Amazon S3
- Role-based permissions and form validation
- Signed webhooks and atomic transactions
- Automated testing and code-quality tools
- Docker containerization

**Technologies:** Python, Django, PostgreSQL, HTML5, CSS3, Bootstrap 5, Stripe, Cloudinary/S3, Pillow, Pytest, Ruff, Git and Docker.
